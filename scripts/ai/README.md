# scripts/ai

本目录用于后续放置 ent AI Engineering Control Loop 的辅助脚本。

计划用途：

- diff summary 生成脚本。
- task boundary checker。
- review packet 生成脚本。
- CI triage 日志裁剪脚本。
- benchmark report 元数据校验脚本，配套模板见 `docs/benchmark-report-template.md`。

当前状态：

- 本轮只建立目录入口和说明。
- 当前不实现复杂脚本。
- 当前不引入 Python 依赖。
- 后续新增脚本必须在任务卡中说明输入、输出、验证命令和失败行为。
